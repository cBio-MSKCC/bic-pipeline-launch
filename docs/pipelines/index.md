# Pipelines Overview

This section tracks the launch surfaces for each pipeline family managed in this repository.

## RNASeq

RNASeq analysis uses `nf-rnaseq` and `nf-diffabundance` workflows plus additional modules.

## MusVar

MusVar is the mouse variants workflow and uses `nf-sarek` with custom additions.

## scRNA

Single-cell launch scripts and supporting material live in the `scRNA/` directory.

## Variants

Variant helper scripts and related launch logic live in the `variants/` directory.
