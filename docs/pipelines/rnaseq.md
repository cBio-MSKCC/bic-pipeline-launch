# RNASeq pipeline

These scripts run the BIC RNA-seq analysis. The analysis has two nextflow pipelines, which are launched one after the other by `run_rnaseq_iris.sh`:

| Step | Pipeline | Code | Installed on iris |
|------|----------|------|-------------------|
| Counts (alignment, quantification, QC) | bic-rnaseq | [github.com/cBio-MSKCC/bic-rnaseq](https://github.com/cBio-MSKCC/bic-rnaseq) | `/usersoftware/core001/common/bic/internal/bic-rnaseq/dev` |
| Differential expression (and optional GSEA) | bic-differentialabundance | [github.com/cBio-MSKCC/bic-differentialabundance](https://github.com/cBio-MSKCC/bic-differentialabundance) | `/usersoftware/core001/common/bic/internal/bic-differentialabundance/dev` |

The installed paths are set at the top of `run_rnaseq_iris.sh` (`bic_rnaseq` and `bic_diff`).

## Where the scripts are

All scripts below are in this directory (`rnaseq/`) unless noted.

| Script | What it does |
|--------|--------------|
| `run_rnaseq_iris.sh` | Main launcher. Submits the bic-rnaseq job, one bic-differentialabundance job per `contrasts*.csv`, and the finalize job to slurm. Must be run on `islogin01.mskcc.org`. |
| `rsync_summary_finalize.sh` | Finalize job, submitted by `run_rnaseq_iris.sh`. See [What the finalize step does](#what-the-finalize-step-does). |
| `bicdelivery_summary.py` | Run by the finalize step to build the delivery summary. This creates files needed to generate bicdelivery's rnaseq summary page |
| `postpipeline_checks.py` | Run by the finalize step. Checks for expected output files, that the genome in the request file matches the genome that was run, that all samples are in the merged counts, and that DE results exist for the groups. Lines it prints that start with `ERROR` are added as a comment on the ClickUp ticket. |
| `close_pipeline_subtasks.py` | Run by the finalize step. Sets `Archive Path` and `Pipeline Version` on the counts ticket and closes it. Then does the same for the differential ticket, and sets `Delivery Path` and `Delivery URL` on the parent ticket. |
| `email_delivery_template.sh` | Sends the delivery email. Needs `email_delivery_config.sh`, which you create by copying `email_delivery_config.sh.dist` and customizing it. |
| `manual_rsync_close.sh` | [I_DON'T_KNOW] (when to use this instead of `rsync_only`) |
| `rsync_excludes.txt` | Files and directories excluded from both rsyncs. |

The automation that creates the analysis folder and starts these scripts is described on the [Automation](../automation/index.md) page.

## Setup analysis folder

The analysis folder is created either by the `auto_start` scripts or by hand. In both cases `run_rnaseq_iris.sh` expects the folder to contain the files below.

### Files used by `run_rnaseq_iris.sh` and the finalize step

| File | Required | Used for |
|------|----------|----------|
| `<project>_request.txt` | Yes | Passed to `run_rnaseq_iris.sh` as the first argument. Read for the genome build and run number, and by the finalize step for delivery. |
| `input.csv` | Yes | The sample sheet. Passed as `--input` to both pipelines, and copied to `project_files` by the finalize step (the finalize step fails if it is missing). |
| `<project>_sample_mapping.txt` | Yes (for finalize) | Copied to `project_files` by the finalize step. |
| `contrasts*.csv` | No | One differential expression job is run for each file. The file name (without `.csv`) is used as the study name. If there are no `contrasts*.csv` files, no DE jobs are run. |
| `gsea_gene_sets.txt` | No | If present, GSEA is run. One gene set file path per line. |
| `*_sample_key*.txt` | No | Copied to `project_files` by the finalize step. |
| `*_sample_comparison*.txt` | No | Copied to `project_files` by the finalize step. |
| `clickup_task_id.txt` | No | Written by `auto_start`. The finalize step reads it to find the ticket to update. If it is missing, the ticket is not updated. |

- `input.csv` and `contrasts*.csv` are generated by `pfg_to_nf_files.py`. See [Generating input.csv and contrasts.csv](#generating-inputcsv-and-contrastscsv).


### Request file fields

These fields are read from the request file by the scripts in this directory:

| Field | Read by | Notes |
|-------|---------|-------|
| `Build` | `run_rnaseq_iris.sh`, finalize | Must be one of `hg19`, `hg38`, `mm10`, `mm39`, `hg38_mm39`. Mapped to the `<build>_local` genome. To add a genome, set it up in the nextflow config for both pipelines and add it to `genome_map` in `run_rnaseq_iris.sh`. |
| `RunNumber` | `run_rnaseq_iris.sh`, finalize | Zero-padded to three digits. The output directory is `r_<run number>`. |
| `PI`, `Investigator` | finalize | Used to build the delivery path. The finalize step exits without delivering if either is missing. |
| `ProjectID` | finalize | Used in the delivery path and the delivery email. |
| `Investigator_Name` | finalize | Used in the delivery email. |
| `DeliverTo_Email`, `PI_E-mail`, `Investigator_E-mail` | finalize | The delivery email goes to the unique addresses from these fields. |
| `Pipelines` | finalize | Optional. If it contains `Fusion-Forte`, the delivery email is skipped. |

### Generating input.csv and contrasts.csv

`input.csv` and `contrasts.csv` are not written by hand. They are created by `pfg_to_nf_files.py`, which is in the [project_file_generation](https://github.com/cBio-MSKCC/project_file_generation) (PFG) repository and is run inside the PFG container (`/pfg/pfg_to_nf_files.py`). The script takes the sample mapping file, the sample key and the sample comparisons, and generates the nf-core style `input.csv` and `contrasts.csv` files for the bic-rnaseq and bic-differentialabundance pipelines.

| Input | Option |
|-------|--------|
| `*_sample_mapping.txt` | `-m` |
| `*_sample_key*.txt` (optional) | `--key` |
| `*_sample_comparisons*.txt` (optional) | `--comparisons` |

The other options `auto_start` passes are `-s <strand>`, `-b <build>`, and `--dir <analysis directory>`, which is where the files are written.

`auto_start` runs this for you once the fastq files have been synced (see the [Automation](../automation/index.md) page). The command it runs is:

```
python /pfg/pfg_to_nf_files.py -m <mapping file> -s <strand> -b <build> --dir <analysis directory> [--key <sample key files>] [--comparisons <sample comparison files>]
```

## Running

On `islogin01.mskcc.org` only:

```
run_rnaseq_iris.sh <request file> <analysis directory> <email> <rsync_dir> [DE_only] [rsync_only] [transcript] [priority] [<additional fasta>.fa]
```

Where:
- `request file` is the full path to the request file.
- `analysis directory` is the full path to the analysis folder (see [Setup analysis folder](#setup-analysis-folder)).
- `email` is your MSK email. It is used for the differential expression failure emails (`--email_on_fail`) and for the finalize job's slurm mail.
- `rsync_dir` is the directory the analysis folder is rsynced to for local archiving, not for delivery. Pass `""` to skip the rsync and finalize step.
- The optional arguments must be given in the order shown. Each one is only recognized if it is next in the list.
    - `DE_only` skips the bic-rnaseq job and runs only the differential expression jobs, then the finalize job.
    - `rsync_only` skips both pipelines and runs only the finalize job.
    - `transcript` uses `params.bic.transcript.yml` instead of `params.bic.yml` for bic-rnaseq.
    - `priority` submits the jobs with `--qos=priority`.
    - A file name ending in `.fa` is passed to bic-rnaseq as `--additional_fasta`. This is for transgenes

The command that was submitted is printed to the terminal. If the script was started by `auto_start`, the output is in `start_pipeline.log` in the analysis folder.

### What the finalize step does

`rsync_summary_finalize.sh` does these things in order:

1. If a GSEA report directory exists, links its `index.html` files so they are easy to find.
2. Copies the mapping file, request file, `input.csv`, and any sample key, sample comparison and contrasts files to `<outdir>/project_files`.
3. Runs `bicdelivery_summary.py`.
4. Rsyncs the analysis folder to `rsync_dir`.
5. Runs `postpipeline_checks.py`.
6. Rsyncs the output directory to the delivery directory `/data1/core002/res/bic/results/<PI>/<Investigator>/<ProjectID>/`.
7. Adds the project permissions command to the bicdelivery queue (`/data1/core001/work/bic/bot01/queues/isvzeta_queue.txt`).
8. Removes the fastq files for the project from `/data1/core001/CACHE/igo`.
9. Sends the delivery email, unless `Pipelines` in the request file contains `Fusion-Forte`.
10. Gets the pipeline versions from the output, and runs `close_pipeline_subtasks.py` to update and close the ClickUp tickets (only if `clickup_task_id.txt` exists).

## Rerunning

Use the same run script with the matching option. For more on running the pipeline by hand, see the [ClickUp documentation](https://app.clickup.com/9006020830/v/dc/8ccty6y-2053/8ccty6y-3273).

| Situation | What to do |
|-----------|------------|
| bic-rnaseq died | Run `run_rnaseq_iris.sh` again without options. Both nextflow commands use `-resume`, so they can reuse the cached work in `<analysis directory>/work`. Whether the work directory is still there after a run: [I_DON'T_KNOW] |
| Differential expression needs to be rerun (or contrasts changed) | Run with `DE_only`. It runs one job for every `contrasts*.csv` in the analysis folder, then the finalize job. |
| The finalize or rsync step failed | Run with `rsync_only`. |
| The automation stopped with an email | Fix the problem named in the email, then uncheck `Email Alerted` on the ticket. The next `find_and_start.sh` run will pick the ticket up again. |
| The run path or archive path already exists | Remove the directory named in the email, then uncheck `Email Alerted`. |
| Restart the automation for a finished or running project | Delete the project folders in the work dir and the rsync dir. Clear the fields that were filled in when the run started (`Run Path` and `Archive Path`) on the ticket and its siblings, which is optional. Set the counts ticket and its sibling tickets back to `to do`. Uncheck `Email Alerted` if it is checked. |
